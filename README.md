# Mahab Qudss Intranet Portal (Internship Prototype)

An enterprise intranet web application developed during an engineering internship at **Mahab Qudss Consulting Engineering Company**. The application was built as a centralized portal prototype for organizational news, document sharing, and employee administration.

## 🌟 Implemented Modules
- **Corporate CMS:** Dynamic publishing of company news, announcements, and media gallery.
- **Document Management:** Centralized repository for company guidelines and organizational documents.
- **Admin Dashboard:** Role-based administration panel for managing content and user sessions.
- **Authentication:** Session-based user state management.

## 🛠️ Tech Stack
- **Backend:** C#, ASP.NET WebForms
- **Database:** Microsoft SQL Server, Entity Framework
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
